# Personal page

this is a simple personal page made using html and css only

## how to use

just open it on browser:

https://subhaintdead.github.io/personal-page/


## dependencies
none!

## how to run locally

copy the commands and paste into terminal:

```bash
git clone https://github.com/subhaintdead/personal-page.git
cd personal-page
npx http-server -p 8000
```
and open it on port 8000

(you may need to download http-server by typing in "y" if you haven't yet)
